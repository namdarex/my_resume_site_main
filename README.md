## ✨ Features

- 🌐 **Bilingual Support:** Seamless switching between Persian (RTL) and English (LTR).
- 🎨 **Dark & Light Mode:** Smooth theme toggling with local storage persistence.
- 📧 **Smart Contact Form:** Sends messages directly to Email (via EmailJS) and Telegram without any backend.
- 📱 **Fully Responsive:** Flawless display across mobile, tablet, and desktop devices.
- ⚡ **Smooth Animations:** Intersection Observer used for scroll reveals, skill bars, and counters.
- 🧹 **Clean Code:** Modular, optimized Vanilla JavaScript with no heavy frameworks.
